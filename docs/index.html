خطوات التشغيل

  1. نزّل الملف وحطه في فولدر لوحده (مثلاً D:\Shop).
  2. كليك يمين على الملف ← Properties / خصائص ← علّم على Unblock ← OK.
  3. افتح الملف واضغط Enable Content / تمكين المحتوى.
  4. ادخل بـ admin وكلمة السر 1234، وغيّر كلمة السر من الإعدادات.

أسئلة شائعة

هل البرنامج مجاني فعلاً؟

أيوه، مجاني 100% ومفتوح المصدر ولا يجوز بيعه. هو عمل خيري لوجه الله.

معنديش Access، أعمل إيه؟

نزّل Microsoft Access Runtime المجاني من موقع مايكروسوفت، والبرنامج هيشتغل عليه.

اسم المستخدم وكلمة السر إيه؟

admin و 1234، وغيّرهم بعد أول دخول من الإعدادات.

محتاج إنترنت؟

لأ، شغال أوفلاين بالكامل وكل بياناتك على جهازك.

الزراير مش شغالة؟

اعمل Unblock للملف من الخصائص، وبعدين Enable Content، أو ضيف فولدره لـ Trusted Locations.
